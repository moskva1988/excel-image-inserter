## What donations fund

- Maintenance time (bug fixes, dependency bumps, Python version compat)
- Code signing certificate for clean Windows installs (~$100/year)
- New features: headless CLI, plan save/reload, drag-reorder
- Documentation and tutorial screenshots

Non-monetary contributions help just as much: file useful bug reports,
write docs, open PRs, share the tool with someone who'd benefit.
